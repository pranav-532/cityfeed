## 🌟 What is CityFeed?

**CityFeed** is a hyper-local campus event discovery and micro-sponsorship platform for college students in Chennai — tailored directly for your city's college cluster (IITM, Anna University, SRM, VIT Chennai).

**Problem Solved:** Thousands of students in every city miss out on accessible local competitions, hackathons, and internships because publicity is trapped inside closed WhatsApp groups and college notice boards. Simultaneously, local businesses waste money on paper flyers trying to reach students with zero measurable ROI.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏆 **Competitions** | Discover case study challenges, quizzes, design contests |
| 💻 **Hackathons** | 24-hour and 36-hour hackathons near you |
| 💼 **Internships** | Chennai-based internship opportunities |
| 🎓 **Clubs** | Follow student clubs and get event updates |
| 🔐 **Auth** | Demo login with student profile |
| 📋 **Apply Flow** | Apply to opportunities with a step-by-step form |
| 🔖 **Save** | Bookmark events for later |
| 🎓 **Club Passport** | Verified record of campus activities (concept) |
| ⏰ **Deadlines** | Sidebar showing upcoming deadlines |
| 🔍 **Search & Filter** | Real-time search + category filters |
